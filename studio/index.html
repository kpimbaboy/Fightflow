Rôle de FightFlow Data Studio

Data Studio résout la fragmentation des données dans la FGC. Il traduit les conventions Tekken (ex: f,n,d,df+2) ou 2D (ex: 236P, qcf+HP) en coordonnées standardisées avec décomposition des pas et calcul automatique de la fenêtre de timing en millisecondes pour l'entraînement sur Hitbox, Stick ou Manette.

Table de Normalisation Automatique

DIRECTIONS TEKKEN ➔ NUMPAD :

f / F (Forward) ➔ 6 (→)

b / B (Back) ➔ 4 (←)

d (Down) ➔ 2 (↓)

u (Up) ➔ 8 (↑)

d/f ou df ➔ 3 (↘)

d/b ou db ➔ 1 (↙)

n (Neutral) ➔ 5 (★)

BOUTONS UNIVERSELS :

1 (Left Punch) ➔ LP

2 (Right Punch) ➔ RP (ou MP)

3 (Left Kick) ➔ LK

4 (Right Kick) ➔ RK (ou HK)

1+2 / 3+4 ➔ LP+RP / LK+RK

> ou , ➔ Délimiteur d'étape / Link
